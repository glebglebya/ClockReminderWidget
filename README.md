# Часы-напоминания — виджет для Android

Приложение + домашний виджет с круглым 24-часовым циферблатом (часовая стрелка
делает полный оборот за сутки, минутная — за час) и настраиваемыми цветными
кружками-напоминаниями вокруг края циферблата.

## Что умеет

- Виджет на главном экране: круглый циферблат, деления на 24 часа, часовая и
  минутная стрелки, обновляется раз в минуту.
- Приложение для управления напоминаниями:
  - **«Через N часов»** — например «красный кружок раз в 7 часов, начиная с
    сегодня с 11:00». Кружок появляется на циферблате каждый раз, когда очередное
    появление напоминания приходится на сегодняшний день.
  - **«Ежедневно, диапазон дат»** — например «зелёный кружок каждый день в 16:00
    с 12 по 15 августа». Кружок появляется в указанное время каждый день, пока
    сегодняшняя дата находится внутри диапазона.
- Любой набор напоминаний может использовать любой из 7 предустановленных цветов.
- При добавлении/изменении/удалении напоминания виджет сразу перерисовывается.

## Как собрать

1. Установите **Android Studio** (Koala/Ladybug или новее).
2. `File → Open…` → выберите папку `ClockReminderWidget`.
3. Дождитесь синхронизации Gradle (первая синхронизация скачает зависимости —
   нужен интернет).
4. Подключите телефон/эмулятор (API 26+) и нажмите **Run**.
5. На главном экране: долгое нажатие → «Виджеты» → «Часы-напоминания» →
   перетащите виджет «Круглые часы 24ч» на рабочий стол.
6. Откройте приложение «Часы-напоминания», нажмите **+** и добавьте напоминания.

## Как это устроено (для разработчика)

- `model/Reminder.kt`, `model/RepeatType.kt` — модель данных (Room entity).
- `data/` — Room-база (`AppDatabase`, `ReminderDao`) и `ReminderRepository`,
  который после любого изменения вызывает `ClockWidgetProvider.updateAll()`.
- `widget/ReminderOccurrences.kt` — превращает правило повторения в конкретные
  «сегодняшние» точки времени (используется LocalDate/LocalTime, java.time).
- `widget/ClockFaceRenderer.kt` — рисует весь циферблат (фон, деления, кружки,
  стрелки) в `Bitmap` через `Canvas`. Виджеты Android не поддерживают
  произвольную кастомную отрисовку в `RemoteViews`, поэтому картинка рисуется
  программно и вставляется как `ImageView`.
- `widget/ClockWidgetProvider.kt` — `AppWidgetProvider`, обновляет
  `RemoteViews` новым битмапом.
- `widget/WidgetUpdateScheduler.kt` + `WidgetUpdateReceiver.kt` — раз в минуту
  через `AlarmManager.setInexactRepeating` запускают перерисовку (пока виджет
  есть на экране; `onEnabled`/`onDisabled` включают/выключают будильник).
  Обновление это неточное (`inexact`), т.к. точные будильники каждую минуту на
  Android 12+ требуют отдельного разрешения `SCHEDULE_EXACT_ALARM` — для
  часового виджета в этом нет необходимости, отклонение в пределах десятков
  секунд не критично.
- `widget/BootReceiver.kt` — восстанавливает будильник после перезагрузки
  телефона.
- `ui/ReminderScreen.kt`, `ui/AddEditReminderDialog.kt` — Jetpack Compose UI
  списка и формы добавления/редактирования (стандартные `DatePickerDialog` /
  `TimePickerDialog`).

## Известные ограничения / что можно улучшить

- Обновление раз в минуту через `AlarmManager` может слегка «плавать» на
  некоторых прошивках при агрессивной оптимизации батареи — при желании можно
  добавить подсказку пользователю добавить приложение в исключения
  энергосбережения.
- Сейчас все виджеты на всех экранах показывают один и тот же общий список
  напоминаний (нет отдельной конфигурации на виджет). Если нужно — легко
  добавить экран конфигурации (`ACTION_APPWIDGET_CONFIGURE`) и хранить список
  per-widget.
- Кружки, которые совпадают по времени (несколько напоминаний в одну и ту же
  точку циферблата), сейчас рисуются друг поверх друга — можно добавить
  небольшое смещение/группировку при коллизии.
